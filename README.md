## Projects

### [Copyrade](https://github.com/abdullah-mi/Copyrade) - *Your clipboard comrade*

Copyrade sends clipboard content from a phone directly to the Windows clipboard through an encrypted WebRTC connection.

It currently supports Google and GitHub authentication, browser-approved Windows device enrollment, device presence, automatic connections, text transfer, and native clipboard delivery confirmation.

**Built with:** TypeScript · React · Electron · WebRTC · Cloudflare Workers

[View the repository](https://github.com/abdullah-mi/Copyrade) · [Open the web app](https://copyrade-staging.abdullahijaz-m.workers.dev)
